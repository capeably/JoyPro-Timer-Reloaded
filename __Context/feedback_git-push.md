Never commit or push unless Adam asks in so many words ("commit this", "push to git").

**Why:** Adam decides what reaches git and the remote; the original JoyPro Timer ran on this rule from the start.

**How to apply:**

- Finish work uncommitted and offer a commit at the end of the task.
- Push only on an explicit request to push, even right after a commit he asked for.
- After a push, follow the ROADMAP workflow in `CLAUDE.md`.
